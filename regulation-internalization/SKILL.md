# 外规内化 Skill

以外规条款为分析起点。模型逐条整理外规义务，查找相关内规，再通过现有控制与证据判断承接和差异。

模型逐条阅读原文并亲自作出关联、适用性、覆盖和定级判断。工具用于提取原文、检索候选、保存模型已写好的记录和导出。候选列表、相似度或脚本规则仅作线索，结论由模型回读原文后写出。

## 审查流程

开始时把下列步骤列入 Todo。每份外规分别跟踪正查、内规回查进度。每审完一条外规就留下[简短的查阅和判断记录](references/review-method.md#边审边记)，完成一份外规后更新 Todo。

1. [确定审查对象和规则效力](references/applicability.md)。核对来源、生效时点、主体与场景。按涉及的机构选读[香港总行](references/jurisdictions/hong-kong.md)、[上海分行](references/jurisdictions/shanghai.md)和[集团与跨法域](references/jurisdictions/cross-border.md)。
2. [逐条外规正查并拆义务](references/review-method.md#读原件并逐条正查)。以外规条款为起点，核适用性，拆成可单独核对的义务，再检索全量输入内规查找相关条款。处理当前规定时，先提取其中的主体、业务、对象、动作、条件、证据及中英文关键词，用 grep 在[术语标准化表](references/materials/terminology.md)中检索；命中后只读相关条目及必要上下文，再回当前规定原文核对，不整表通读，也不把关键词命中直接当作术语等效。其他解释和业务材料按[资料索引](references/materials/index.md)查阅。
3. [从义务映射到控制](references/review-method.md#从制度条款核到控制动作)。用原文位置或简短引用关联义务、控制和内规条款。按[场景与证据](references/control-evidence.md)核对现有控制的设计以及材料能证实的执行情况。
4. [用同一判断回查内规承接](references/review-method.md#逐项反查)。对每份内规复核与本制度有关的外规义务，包括外规正查未命中的义务。记录承接和覆盖的去向，拟判整项缺失时写清最接近的控制和未覆盖理由，不另改适用性、覆盖、证据和差异判断标准。
5. [分批归并、分类和定级](references/review-method.md#定级并整理问题)。正查或回查完成一批时，就把已有证据的发现和此前记录对照，确定主承接制度、区域、差异类型、原文位置和等级，再按归属[更新累计记录及 HTML](references/results.md#分批写入与更新)。差异类型取漏洞、差距、冲突、重复控制、过度控制、责任缺口或证据缺口，与高、中、低风险等级分别判断。余下条款继续审查。
6. **[模型终检并自行修正](references/results.md#模型终检并自行修正)。** 打开实际写出的 HTML，在外规视图中逐张回读全部卡片及字段，和正查、回查工作笔记及问题清单对照，确认依据、主承接制度、区域、差异类型、重复情况和等级。发现错误，模型直接修正记录，重新导出，并复看改动卡片。内容终检由模型按提示词完成，禁止使用检查脚本或程序代替判断。终检后按[HTML 交付](references/results.md#html-交付)附上独立 HTML 和待核事项。

工作记录用 Markdown 或当前可用的笔记形式保存。资料缺失、个别事项待核或工具局部报错时，记明影响范围和进度，其余审查和已确认结果的交付继续。需要用户澄清、确认或人工复核的事项随交付结果集中提示。

## 其他材料按需选读

以下辅助材料按本次审查主题选读。

- 专项业务判断查[银行业务与控制核对点](references/banking-controls.md)。有版本变化或过渡期时再读[新规和版本变化](references/regulatory-change.md)。
- 需要提出整改动作、责任或验证方式时，查[整改设计与验证](references/remediation.md)对应部分。仅有制度材料时先按能确认的设计证据交付审查结果。
