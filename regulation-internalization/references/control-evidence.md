# 场景与控制证据

用于正查和反查中的覆盖判断，尤其是看似写了同一要求、使用等效控制、存在例外或疑似运行偏差时。

## 先确定证据支持哪一层

| 材料 | 可以判断的范围 |
| --- | --- |
| 政策、制度、授权文件 | 已规定的要求、适用条件、分工及控制设计。 |
| 流程、表单和操作手册 | 业务步骤、执行和复核动作、记录字段、异常和例外安排。 |
| 现行配置、规则版本、系统字段或权限 | 在对应环境和版本中，系统如何触发、拦截、授权、计算或记录。 |
| 日志、交易样本、审批和报送记录 | 样本所涉期间中控制是否执行、作了什么动作、输出结果如何。 |
| 审计抽样、独立复测和持续监控 | 在已有验证覆盖的期间或样本内，是否持续有效或已验证整改。 |

使用现场提供的证据核对主体、场景、版本和期间一致。制度文本即可支持明确的设计冲突，但只有制度文本而义务所需的流程、模板、权限或系统承接缺失时，不得标为完全覆盖；系统控制是否必需由适用义务决定。没拿到系统材料时把配置或执行结论留待核；已证实记录字段、日志或证据机制缺少规定，再按其具体依据判断证据缺口。

## 在分析中核对场景

- **应触发**。给出满足适用条件的一种业务情形，核现有制度是否会启动要求的控制并形成记录。
- **不应触发**。确认范围外主体、交易或资料是否会被误纳入，借此识别不必要的审批、采集、拦截或上报。
- **边界与例外**。涉及阈值、时限、切换或允许的人工例外时，查恰好等于门槛、跨期、补正、授权或超时的动作。以适用原文和现行规则说明预期结果。
- **控制失效**。查控制失效以后谁能发现、怎样升级或补救。评估影响时指出实际失败动作与受影响对象，已发生的事实按证据描述。

以上情形可以用来阅读和比较材料，也可用于有样本时的验证。只用与当前义务相关的场景。

## 等效与补偿控制

逐项比较所覆盖的对象、触发、结果、授权和证明责任。替代方式能覆盖监管目标时核其适用依据和限制。补偿控制应看运行时点、独立复核、可验证证据、期限、退出条件及剩余风险。多处措施共同承接时记录各环节实际承担的义务。一处控制失效而仍有其他有效控制时，按未被覆盖的部分评价影响。
