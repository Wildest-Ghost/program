# 问题记录和 HTML 导出

## 问题记录

边查边记义务、覆盖和问题。模型按[最终问题清单](review-method.md#从笔记形成最终问题清单)中确认的制度归属、区域、差异类型和等级，把各问题写到主承接内规的 UTF-8 JSONL。每行一个 JSON 对象，`区域` 取「条款差异」或「制度级缺口」，其他键直接使用对应 HTML 字段名。无问题可用空文件保留该内规的输入记录。

`差异类型` 取「漏洞」「差距」「冲突」「重复控制」「过度控制」「责任缺口」或「证据缺口」，认定方法和举证要求见[差异类型](review-method.md#差异类型)。它是独立字段，不替代高、中、低风险等级，也不只写在风险简述里。每条问题填一个主差异类型；风险简述仍写清具体义务、现有控制、差异及影响。

查阅范围、无差异、排除理由和待核事项保留在模型工作记录里。最终问题记录由模型从已复核的发现整理，导出器读取并写入独立 HTML。

每次写入按当前清单里的主承接制度、区域、差异类型和等级归类。最终内容核对见[模型终检并自行修正](#模型终检并自行修正)。

| 区域 | 字段及顺序 |
|---|---|
| 条款差异 | 风险等级、差异类型、风险简述、内规条款号、内规正文、外规依据、具体差异、修改建议 |
| 制度级缺口 | 风险等级、差异类型、外规文件名、外规条款号、外规正文、缺失分析 |

条款号和正文直接取自确认过的原件位置。外规依据写文件名、条款号和相关原文；多份依据用空行分隔，每份首行写「外规文件名｜外规条款号」，后续行写相关原文。风险简述保留完整表达。缺失分析说明适用、承接和全文未覆盖的根据。

需要英文内容时，在原字段名后加 `_en` 填写对应英文，例如 `风险简述_en`、`内规正文_en`、`外规依据_en`、`具体差异_en`、`修改建议_en` 和 `缺失分析_en`。多份英文外规依据的顺序与中文一致。制度级缺口也可填写 `外规文件名_en`、`外规条款号_en` 和 `外规正文_en`。未提供英文的字段回显原字段内容，不由导出器擅自翻译或删减。

用到解读材料时，条款差异在「外规依据」的原文后追加解读出处，在「具体差异」写清其作用。制度级缺口在「缺失分析」中写解读出处和作用，「外规正文」填写外规原文。

同一份制度涵盖多家机构时，在「具体差异」或「缺失分析」里明确问题对应香港总行还是上海分行，并写明实际适用场景。每份内规可记录其覆盖的不同机构。限定为集团政策、合同或代理行义务的，在依据与分析里写清来源性质。

## 分批写入与更新

逐条审查，按有意义的批次更新成果。小文件可按一份外规的正查或内规回查为一批，长文件可按章节或一组已逐条核对的条款为一批。遇到足以单独确认的发现，也可先写入一条。

每批有新增或变更的已确认发现时，更新各内规的累计 JSONL，再用当前全部记录刷新同一份 HTML。批内尚待核实的候选保留在工作笔记。阶段版的已审范围和待审范围用进度记录说明。导出工具暂时不可用时，先保存该批分析和已确认问题，继续审查，等可导出时按累计记录写盘。

后续批次发现同一问题时更新现有记录。归属变化时把它移到正确的制度和区域，新增依据时补在原问题上，证据推翻结论时撤销原问题。跨制度复核完成后，用累计记录的最终版本刷新 HTML。

## 导出 HTML

用 Python 3 标准库从最终问题记录直接生成一个独立 HTML，不依赖外部 CSS、JavaScript、字体或网络资源。个别记录缺字段时照常写可用内容；读取不了的 JSONL 行提示文件及行号，其他行继续导出；文件无法读取时，其他内规也继续导出。

```sh
python scripts/write_html.py "内规名称.jsonl" "另一份内规.jsonl" --output "结果.html"
```

HTML 全部按外规组织。每份外规对应一个页签，页签、外规条款和内规记录的顺序按其在最终问题记录中的首次出现顺序保留。页签内仅有外规条款卡片这一种展示类型，不设置其他问题分区或分类汇总，全部高、中、低风险记录均在同一卡片序列中展示。

外规条款根卡片直接显示外规条款号和外规原文，不重复设置外规正文子卡。点击展开后，逐份显示相关内规文件、内规条款号和内规正文，再显示风险简述及具体差异，最后显示修改建议。一条内规问题引用多份外规时，分别挂到对应外规条款下，原记录的所有字段均保留。风险等级用红、黄、绿文字标签区分，差异类型另用彩色标签区分，不设置卡片左侧风险边线。

没有有效承接的外规条款也在同一卡片序列中展示，点击展开后直接显示主承接内规和缺失分析。无记录时仅显示「暂无记录」。

HTML 支持当前外规的全文搜索、风险等级筛选、差异类型筛选、全部展开、全部收起和页签切换。筛选只影响当前浏览，不删改、摘要或重排原始记录；清除筛选后恢复全部记录及原顺序。打印时展开全部页签和卡片。

右上角支持中文和 English 切换。固定界面由模板翻译；分析内容使用对应 `_en` 字段，未提供英文时保留原字段内容。切换语言不改变记录、筛选结果或原文依据。

## 模型终检并自行修正

> 打开已经写出的 HTML，拿正查、回查工作笔记和最终问题清单作依据。逐份外规、逐张读实际写入的卡片，碰到不一致就自己修正。用工具读取 HTML 卡片及字段，用模型逐条对照和判断。内容终检禁止写或运行检查脚本，也不调用规则程序代替复核。

1. **内容和分析一致。** 对照笔记和原文位置，核每条记录的义务、适用主体、控制差异、差异类型、等级和建议。确认仍能由同一条证据支持，摘要有标注，卡片叙述和工作笔记里的覆盖结论一致。
2. **分类、归集和分区一致。** 差异类型须满足[成立条件和举证要求](review-method.md#差异类型)，不得仅因关键词未命中判漏洞，也不得仅因未逐字复述外规判差距。条款差异的相关内规定位与最终问题记录的主承接制度一致；制度级缺口的承接责任与全文核对依据也一致。分析中写有「整项未覆盖」时检查是否应归入漏洞和制度级缺口。比较各外规页签及卡片，确认同一缺陷只在主承接位置出现一次，不得在另一记录换用「保存期限」「可重现性」等近义表述重复列示。引用和受影响的其他制度写进该条分析。
3. **HTML 完整一致。** 从实际写出的 HTML 逐张卡片及字段核对最终问题记录。外规根卡片保留外规原文，展开后的相关内规、风险简述、具体差异、修改建议和缺失分析均不得省略。包含全部高、中、低风险，不得只展示高风险、另行摘要、过滤、截断或合并分析内容。无记录时显示「暂无记录」。分别切换中英文检查界面及已有英文字段，未翻译字段按原内容显示。汇报数量时使用这批已复核的问题记录，并可按差异类型分组说明。

发现不一致时，模型自行更新最终问题记录，必要时同步更正分析笔记，然后重新导出并回读受影响的卡片。证据不足的个别发现标待核。无法打开 HTML 回读时，模型仍对照笔记和导出输入记录，交付已写出的文件并说明实际检查范围。

## HTML 交付

终检后交付独立 HTML 文件。回复提供 HTML 文件链接，并集中提示需要用户澄清、确认或人工复核的事项；需要汇报数量时，按实际写入 HTML 的最终记录统计。

源记录字段及顺序固定如下：

```markdown
条款差异：
风险等级｜差异类型｜风险简述｜内规条款号｜内规正文｜外规依据｜具体差异｜修改建议

制度级缺口：
风险等级｜差异类型｜外规文件名｜外规条款号｜外规正文｜缺失分析
```

导出确实受阻时，仍按最终问题记录交付已确认的问题及阻碍说明。
