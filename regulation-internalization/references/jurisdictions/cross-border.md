# 集团标准与跨法域适用性

涉及一项制度覆盖两地、集团共享服务、境外制裁或代理行要求、跨境支付、资金或资料流动时读本页。

## 先画实际关系

从谁签约、谁发起、谁执行、谁接收和谁保管找连接点。支付查币种、付款参与方和实际清算路径。数据查收集或处理主体、目的、字段、系统、远程访问、接收方和所在地区。总部与本地分行各自承担的义务按实际主体与控制环节判断。

## 按依据判断约束

| 依据类型 | 核对方式 |
| --- | --- |
| 当地直接义务 | 找适用主体、场景、期限与例外的原文，分别确定每地最低标准。 |
| 域外规则 | 找具体条文及适用连接点，例如人员、交易、资产、清算路径或合同。区分法定约束和间接业务影响。 |
| 合同或代理行 | 查实际条款、通知、服务链和承担义务的实体。判断客户、供应商或集团内部协议各自约束谁。 |
| 集团政策 | 确认有权发布的适用版本、适用机构、本地采纳与例外。集团标准加严时，复核本地法、牌照及对客户或数据的影响。 |
| 事实影响 | 说明可能受影响的业务和连接点，用于查证或评价后果。缺少义务依据时，保留为事实影响或待核。 |

## 识别冲突和主承接

在同一主体、场景和时点下，按需要核法规与法规、法规与牌照、集团与本地、内部制度与流程或系统的一致性。两项要求能同时满足时分别保留其来源和承接位置。发现实际冲突时写清受影响实体、互斥动作、涉及的业务或数据以及需要核实的例外、批准或澄清。

集团负责共同控制时，先查主政策和执行安排，再查当地细则如何引用、执行或补充。若一个共同控制影响多份制度，把关联关系记在同一控制上。两地独立义务、各自执行缺陷或改法不同的，按各自情况形成发现。
