# 香港总行适用性核对

涉及香港总行、在港接受监管的实体或由香港实质管理的活动时读本页。集团义务、境外机构和跨境链路同时查[集团与跨法域](cross-border.md)。

1. **锁定机构和活动。** 从监管登记、认可或注册状态和批准范围确认辨识出的法人。区分本行办理、集团其他实体办理、代理销售及第三方提供。证券、保险、支付或其他受规管活动分别核适用资格和业务材料。公开网页可证明其披露内容，实际经营和权限用对应记录支持。
2. **核对业务落点。** 对照相关原文看客户关系实质在哪管理、账户或交易在哪记账、谁签约、哪个岗位或系统处理。规则使用的连接点以条文为准。开户、偶发交易、持续关系和第三方代办各自核相应触发。参考术语资料，并按香港原文确认本地定义。
3. **判定来源的作用。** 区分香港法例及附属法例、按法定授权发布的监管指引、通函、问答、守则、执法案例和行业标准。逐一记录该材料解释哪一义务、适用于哪类机构或活动、是否增加可执行条件。用案例识别失效情景和可核证据，案例事实的适用范围以其文书为准。
4. **找到当地承接。** 核总行政策或本地操作规则如何覆盖该场景，查看集团条款、流程授权和系统的实际引用关系。涉及客户、期限、例外和参数时，以香港适用依据为判定基准。另有确实适用的集团或合同要求时单列性质与承接依据。

反洗钱、受规管销售、私隐或资料共享等具体业务按[银行业务与控制核对点](../banking-controls.md)选择章节。
