# 审查对象、规则效力与适用性

## 确认范围和适用性

用用户提供的文件、版本和审查时点定范围。先辨认每份材料是监管原文、解读、内规、执行材料还是业务事实。一份制度涉及香港总行和上海分行时，各自查适用条件。集团统一发文只能说明存在集团文件，承接对象以文件适用范围和执行安排为依据。材料里无法辨认现行版本时，记录争议范围及还需要的原文或版本证明。

| 先查什么 | 怎么判断 |
|---|---|
| 机构和职责 | 找条文定义和适用条款，明确是香港总行、上海分行、其他实体、受托机构还是某类人员有义务。区分对集团的要求、由分行实际执行的环节和监管机构自身职责。再核查这份内规的适用范围、被引用关系和职责分工。 |
| 牌照与实际业务 | 根据可取得的牌照、批准、产品资料或业务记录核对许可范围和实际经营。核实产品、客户、交易及渠道，区分持牌、受条件限制、获豁免和实际开展。历史公开名单只支持其所载期间的事实。 |
| 义务触发 | 核对业务阶段、客户或交易类型、产品、金额或风险等级、境内外环节、结算链路、数据流向等实际条件。把适用定义和例外与触发动作一起读。 |
| 来源性质 | 标清发布主体、法域、文件性质、外规原文和适用依据。区分法律或监管义务、解释或监管期望、集团标准、合同或代理行要求、业务影响。境外要求须写明具体连接点和据以承接的方式。 |
| 时点与版本 | 区分发布、现行版本生效、修订、替代、停用和过渡期。对新增、修改、废止、澄清分别判断变化了什么。明确适用新业务、存量关系、在途交易还是持续义务，查清过渡期和历史补救依据。 |

集团标准可能覆盖本地义务，也可能另外加严。需比较两者的执行动作及本地法律、牌照或例外是否允许。遇到跨法域或集团与本地要求冲突，先核双方来源、适用实体和触发事实，记录需要澄清的冲突点及受影响的业务。集团、合同和代理行义务使用与来源性质一致的措辞。

把范围和判断落实到具体义务。业务、牌照、版本、数据流或责任仍缺证时，在工作记录写明影响哪项判断和需要什么材料。已明确适用的事项继续。只有标题时，可先定位相关主题和需要的原文，等正文取得后再定条款级差异。

同一义务可对两地得出不同结论。按主体、牌照与实际业务、触发场景和跨法域连接点依次核对，记录为适用、条件适用、不适用或待核，并简记原因。条件适用时写清条件是否已满足。集团、合同或代理行要求须能指出来源和本机构的承接依据。事实影响可帮助检索和分析后果。

## 主体与情形入口

- [香港总行](jurisdictions/hong-kong.md)。核认可机构身份、受规管活动、客户与业务关联，以及监管指引在本场景的作用。
- [上海分行](jurisdictions/shanghai.md)。核分行资格、许可范围、业务对象、管理行与分行分工，以及本地控制位置。
- [集团与跨法域](jurisdictions/cross-border.md)。核集团标准、本地直接义务、合同安排和跨境资金或数据连接点。两地同时涉及的义务按主体分别落判断。

## 记录关键依据

可在工作记录用一行保存判断：

```text
外规条文及版本｜生效时点｜适用主体及业务场景｜直接/集团/合同/事实影响｜适用结论｜依据或所缺证据
```

规则原文和正式解释分别注明出处，便于反查时沿用同一判断。资料卡或二手解读标注为摘要。公开名单能证实所载时点的分类，牌照能证实许可的活动和限制，实际经营、内部承接和运行情况各有对应证据。主体或业务条件未确认时，保留具体待核依据和受影响的义务。
